# PDF Extractor Privacy Policy

**Draft — publish this at a public HTTPS URL and review it before submitting the extension.**

PDF Extractor detects PDF requests on its configured supported website and document host so it can offer open and download actions.

## Information processed
The extension may store PDF URLs, filenames, content lengths when provided by the server, and timestamps indicating when a PDF was detected.

## Storage and sharing
This information is stored locally in the user's browser using extension storage. The extension does not transmit this information to a developer-operated server, sell it, or use it for advertising.

## User control
Users can clear the extension's detected-document history from the popup. Removing the extension removes its locally stored extension data according to browser behavior.

## Permissions
The extension uses request observation to detect PDF responses from its configured host, local storage to retain the detected list, downloads to download selected PDFs, and tabs to open selected PDFs.
