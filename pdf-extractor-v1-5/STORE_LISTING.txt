CHROME WEB STORE LISTING DRAFT

Name:
PDF Extractor

Short description:
Find PDF documents loaded by supported websites and open or download them in one click.

Detailed description:
PDF Extractor detects PDF documents loaded from its configured document host and keeps a local list of detected documents. Open a document in a new tab or download it from the popup. The extension includes a refresh control and a clear-history option.

Compatibility:
This build is configured for one specific e-learning website and its PDF delivery host. It is not a universal PDF detector. The supported site and host must be accurately disclosed in the final listing before publication.

Privacy:
The extension stores detected PDF URLs, filenames, approximate sizes when available, and detection timestamps locally in the browser. It does not send this information to a developer-controlled server. Users can clear the local list from the popup.

Permission rationale:
- webRequest: identify PDF responses from the configured document host.
- storage: keep the locally detected PDF list.
- downloads: download a selected PDF.
- tabs: open a selected PDF in a new tab.
- Host permissions: limit request monitoring to the configured e-learning site and document host.
